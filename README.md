# Paulina: Data for the Public Domain

This project aims to build a global and multilingual search engine for authors
and works in the public domain using Wikidata and Python.

## Requirements
* Python 3.10 or later.
* Python modules: flask, pywikibot, python-dateutil

## Website
Public alpha version available at <https://paulina.toolforge.org/>.
