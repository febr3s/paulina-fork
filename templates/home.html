Search engine

Paulina Project aims to create a global and multilingual search engine for authors and works in the public domain using Wikidata and Python. This is a preliminary version of the tool.

Local tools

This search engine is part of a larger project to facilitate the creation of national, regional or thematic versions of the tool, according to the needs of each community.

Wikidata

We use data tools as participatory research instruments to help improve information about the public domain on Wikidata and, through it, on the Internet.
