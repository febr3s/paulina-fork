About Paulina

Paulina project invites you to learn about the cultural heritage of humanity. Powered by Wikidata, it allows you to search for people and find out if they have freely accessible works in the public domain. It also helps to improve the information about the public domain on Wikidata.

Paulina is supported by Ártica - Centro Cultural Online, Creative Commons Uruguay, DATA Uruguay and Wikimedistas de Uruguay.

Visit the project's code repository.

This website is still in a preliminary version.
